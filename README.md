# 🧪 ElixirOfLife | إكسير الحياة

> تطبيق ويب تفاعلي يحتفي بالماء باعتباره السر الأساسي للحياة.

مشروع **ElixirOfLife** هو تطبيق ويب تقدمي (PWA) يجعل استكشاف أهمية الماء تجربة يمكن الوصول إليها من أي جهاز وتعمل حتى **بدون اتصال بالإنترنت**.

## 🌐 الموقع المباشر
يمكنك زيارة الموقع الحي هنا:  
🔗 [https://namr97002-boop.github.io/ElixirOfLife/](https://namr97002-boop.github.io/ElixirOfLife/)

## ✨ المميزات الرئيسية
*   **⚡ سريع ويعمل دون اتصال** بفضل تقنية Service Worker.
*   **📱 متجاوب** مع جميع أحجام الشاشات.
*   **🔓 مفتوح المصدر** مبني بتقنيات الويب القياسية.

## 🚀 كيفية البدء
1.  زر **الرابط أعلاه**.
2.  استمتع بالمحتوى، حتى لو اختفى الإنترنت!
3.  (اختياري) استخدم خاصية **"تثبيت التطبيق"** في المتصفح لتجربة تشبه التطبيق الأصلي.
